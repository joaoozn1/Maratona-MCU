MARATONA MCU — site pessoal responsivo

1. Abra index.html em um navegador moderno.
2. Para usar no celular como site, publique index.html em uma hospedagem estática HTTPS (GitHub Pages, Netlify, etc.) e abra o endereço no celular.
3. No Safari do iPhone, use Compartilhar > Adicionar à Tela de Início. No Chrome Android, use o menu > Adicionar à tela inicial.
4. O progresso fica no armazenamento local do navegador. Use Dados > Exportar backup regularmente. Não há sincronização automática entre dispositivos. Alguns navegadores não permitem armazenamento em arquivos locais.
5. Os pôsteres vêm de um serviço externo e exigem acesso à internet; se não carregarem, aparece a identificação do título. O restante do site não depende de bibliotecas externas.
6. As datas da história são aproximadas quando não confirmadas; os X-Men e o Quarteto Fantástico são posicionados por conexão narrativa. Doutor Destino é uma meta futura, não entra nos 57 títulos.
